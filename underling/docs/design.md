# 地下小勇者 · 一页纸设计文档（GDD）

## 一句话

在一个会发光的苔藓洞窟里，玩家遇到一只害怕你的苔团；你可以打它，也可以让它安心、
放它走。**核心问题：当你拥有伤害它的能力时，你会怎么选？**

## 目标体验

- 时长：5～8 分钟一轮，可重复通关。
- 情绪：安静、微亮、有点孤独；幽默只在文本里，不破坏氛围。
- 致敬《传说之下》的**战斗即对话**：战斗菜单不只是数值，也是表达态度的方式。

## 核心循环（90 秒内可完整体验一遍）

```
探索洞窟 → 靠近苔团 → 战斗
   ├─ 战斗（时机判定，造成伤害）
   ├─ 行动（检查 / 安慰 / 讲笑话，推进关系）
   ├─ 物品（苔藓药水 +10 HP）
   └─ 饶恕（安慰两次后解锁）
→ 敌人回合（红心躲弹幕）
→ 回到菜单，或进入结局
```

## 平台与技术

- 平台：桌面浏览器（键盘），960×600 逻辑分辨率，等比缩放居中。
- 技术：原生 HTML5 Canvas 2D + WebAudio 合成音效，零依赖、零外部素材。
- 为什么不用引擎：本轮目标是验证核心循环与手感，浏览器原型改一行就能刷新；
  若要扩成完整作品，再把状态机与数值原样搬去 Godot。

## 角色

| 角色 | 设定 |
| --- | --- |
| 小光（玩家） | 掉进洞窟的小勇者，LV 1，HP 20，带 2 瓶苔藓药水 |
| 苔团 | 洞窟里的苔藓团，HP 30，攻击 0，防御 2；害怕陌生人，被安慰两次后愿意被饶恕 |

## 数值

- 玩家 HP 20；中弹 -3，受伤后 0.9s 无敌。
- 判定条 1.15s 扫过全程；按精度造成 7 / 5 / 3 / 1 伤害，挥空 0。
- 敌人回合时长 6.0s + 0.3s×回合数（上限 8.4s）。
- 弹幕交替：奇数回合「孢子雨」（间隔 0.36s−0.02s×回合，下落 150～210+8×回合），
  偶数回合「弹球」（3 + min(3, 回合/2) 个，190 px/s，碰壁反弹）。
- 饶恕阈值：安慰/讲笑话累计 2 次。

## 状态机（battle.js）

```
msg → menu ⇄ act / item / mercy
menu → fight → attack → msg → enemyturn → msg → menu
hp<=0 → dead →（按 Z）新 Battle
spare / kill → EndingScene；flee → WorldScene
```

## 内容范围（本轮）

- 1 个洞窟房间、1 个敌人、2 个结局、1 首流程（无存档、无音乐）。
- 明确不做：商店、装备、多敌人、技能树、过场动画。

## 里程碑

1. **Prototype（已完成）**：核心循环可玩、两种结局可达、逻辑测试通过。
2. **Vertical Slice**：加入第 2 个敌人与 1 段分支对话，音乐与音效打磨。
3. **Alpha**：3 个房间、存档、设置项（音量/按键）。
4. **Beta**：完整流程 20～30 分钟，外部试玩与数值调整。

## 风险与对策

- **“像 Undertale”变成“抄 Undertale”**：角色、文本、美术全部原创，只保留玩法语言。
- **战斗很快变成纯数值**：把「行动」写成角色表达，饶恕需要先建立关系。
- **弹幕太难/太无聊**：固定 6 秒回合、固定 -3 伤害，先保证可读性再加花样。
