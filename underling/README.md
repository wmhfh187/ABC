# 地下小勇者 · UNDERLING

一个**致敬《传说之下》的原创小游戏原型**：回合制对话 + 红心躲弹幕 + 饶恕或战斗。
全部画面、角色、文本、音效均为原创（代码直接合成音效，不含任何外部素材）。

纯 HTML5 Canvas，**零依赖、无需安装引擎、无需联网**。

---

## 运行

**最简单**：直接双击 `index.html`，用浏览器打开即可玩。

或者起一个本地服务（避免个别浏览器对 `file://` 的限制）：

```bash
# 仓库根目录
python -m http.server 8123 --directory underling
# 然后打开 http://127.0.0.1:8123/
```

## 操作

| 按键 | 作用 |
| --- | --- |
| 方向键 | 洞窟里移动 / 战斗中移动红心 / 菜单选择 |
| Z · Enter · Space | 确认、对话继续、在判定条上停住光标 |
| X · Esc · Shift | 返回上一层菜单 |

## 玩法

1. 标题画面按 Z 开始，在苔藓洞窟里向右走。
2. 靠近苔团按 Z 进入战斗。菜单：**战斗 / 行动 / 物品 / 饶恕**。
3. 「战斗」是时机判定：光标越靠近中间伤害越高（7/5/3/1）。
4. 「行动」可以检查它、安慰它、讲笑话。**安慰两次**后「饶恕」解锁。
5. 敌人回合：红心在方框里躲孢子与弹球，中弹 -3 HP。HP 归零会倒下，按 Z 可以重来。
6. 结局有两种：**饶恕 → 温柔的路**，**击杀 → 沉默的洞窟**。逃跑则回到洞窟。

## 目录

```
underling/
├── index.html          入口
├── css/style.css       页面样式（黑底居中、像素化缩放）
├── js/
│   ├── core.js         画布 / 输入 / WebAudio 合成音效 / 文字与绘图工具
│   ├── battle.js       战斗场景：回合状态机、判定条、弹幕、菜单、结局
│   ├── scenes.js       标题 / 洞窟探索 / 结局，以及通用对话
│   └── main.js         启动与主循环
├── docs/design.md      一页纸设计文档（GDD）
└── tools/logic-test.mjs  无头逻辑冒烟测试（Node 22+）
```

## 开发验证

在 Node 里用假 canvas 跑完整状态机（不需要浏览器）：

```bash
node tools/logic-test.mjs
```

覆盖：标题 → 洞窟 → 对话 → 接近敌人 → 战斗菜单 → 行动/安慰 → 解锁饶恕 →
两轮弹幕 → 饶恕结局 → 回标题；以及 FIGHT 伤害判定、药水、击杀结局、逃跑、
中弹死亡与重试。当前 34 项断言全部通过。

> 浏览器里实际打开确认；逻辑与数值已由上面的测试覆盖。
